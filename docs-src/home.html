CodeMirror

Extension:CodeMirror provides a standalone editor in MediaWiki with syntax highlighting and other advanced syntactical editing features using the CodeMirror library. It supports a variety of languages, notably MediaWiki wikitext, JavaScript, CSS, JSON, Lua and Vue.
