Wikitext highlighting classes

Every CSS class the CodeMirror wikitext mode applies, with an example of each. Override any of them in your personal CSS to change how the editor looks.

The examples are generated from the mode itself, so the classes are always the ones you will see while editing. Some things, such as line height and font size, have no effect in the 2017 wikitext editor.

This browser does not support the CSS Custom Highlight API, which the VisualEditor source mode needs.

Playground

A real editor, with the same bracket and tag matching as a wiki, so you can type your own wikitext and put the caret on a bracket to see it match.

This is the highlighting on its own. The editor on a wiki does more: line numbers, the active line, autocomplete, code folding, closing brackets and tags, linting, search and replace, and marks for special characters and whitespace. You turn those on and off in the editor's own settings, and none of them are here.
